МЯУКАЛО — ЗВУК ВКЛАДКИ (расширение для Chrome, Edge, Яндекс Браузера, Opera, Brave, Vivaldi)

Установка (один раз):
 1. Откройте в браузере адрес  chrome://extensions  (в Edge — edge://extensions, в Яндексе — browser://extensions).
 2. Включите «Режим разработчика» (переключатель справа вверху).
 3. Нажмите «Загрузить распакованное» и выберите ЭТУ папку.
 4. Закрепите значок расширения на панели (иконка пазла → булавка).

Использование:
 • Откройте вкладку (например, YouTube), нажмите значок Мяукало (или Alt+Shift+M).
   На значке появится ON — звук вкладки идёт в программу, а в самой вкладке он продолжает звучать.
 • В Мяукало: «Коммутация» → панель «Источники» → раздел «ВКЛАДКИ БРАУЗЕРА» → перетащите вкладку на схему.
 • Повторное нажатие значка — остановить. Можно передавать несколько вкладок одновременно.
 • Если программа не запущена, на значке «…» — расширение само подключится, когда Мяукало откроется.

Firefox не поддерживается (в нём нет нужной функции захвата вкладок).
Звук передаётся только внутри компьютера (127.0.0.1), в интернет ничего не уходит.
